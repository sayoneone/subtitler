# Subtitler

Настольное и мобильное приложение для следователей: видео с речью на турецком
или узбекском → то же видео с вшитыми русскими субтитрами, с проверкой и
правкой каждой реплики перед вшиванием.

- Платформы: Windows 10/11 (portable ZIP, без прав администратора) и Android 8+ (APK).
- Распознавание: Yandex SpeechKit v1, перевод: Yandex Translate v2.
- Своего бэкенда нет: каждый пользователь вводит собственный API-ключ Яндекс
  Облака при первом запуске, ключ хранится только локально (Credential Manager
  / Android Keystore).
